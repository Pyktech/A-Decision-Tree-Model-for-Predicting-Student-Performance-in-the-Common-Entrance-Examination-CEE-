# Student Performance Predictor

This project predicts student performance in the Common Entrance Examination (CEE) using a Decision Tree Classifier.

## Features Used
- Gender
- Time spent studying
- Medium of instruction
- Class X Percentage
- Class XII Percentage
- Father's occupation
- Mother's occupation
